# Project Instructions

## Keep the in-game help current

Whenever a control, hotkey, tool, workflow, or gameplay rule changes, update the relevant room-specific `?` guide in the same change. Review all three guides regularly as features are added:

- Main game / How to Play
- Custom build mode / Free Build Guide
- Apartment / Apartment Controls

Keep each guide specific to its room and mode. Do not replace these player-requested guides with automatic tooltips.
